01 · MASTER ROUTE

모든 요청이 처음 거치는 결정 그래프

  1. 1사용자 요청최신 목적·대상·출력
  2. 2권위·안전 경계플랫폼 → 사용자 → 공개 공통 규칙
  3. 3요청 유형대화 / 읽기 / 수정 / 외부 상태
  4. 4정보원·도구로컬 / 웹 / 브라우저 / connector
  5. 5최소 스킬가장 구체적인 domain 0–1개씩
  6. 6검증·완료·보고증거 → 허가 상태 전환 → 결과

상태 변경

C
