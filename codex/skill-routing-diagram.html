01 · MASTER ROUTE

모든 요청이 처음 거치는 결정 그래프

실선은 기본 실행, 점선은 조건부 진입, 붉은 선은 승인·입력·도구가 없을 때의 중단을 뜻한다.

실행조건참조대체·배제중단
  1. 1사용자 요청최신 목적·대상·출력
  2. 2권위·안전 경계플랫폼 → 사용자 → 공개 공통 규칙
  3. 3요청 유형대화 / 읽기 / 수정 / 외부 상태
  4. 4정보원·도구로컬 / 웹 / 브라우저 / connector
  5. 5최소 스킬가장 구체적인 domain 0–1개씩
  6. 6검증·완료·보고증거 → 허가 상태 전환 → 결과
기본 종료

일반 대화·안정적 사실·번역

요청→답변

수명주기·도메인 스킬 없이 답한다. 호스트가 공통 규칙을 지정했다면 최종 답변 표현만 적용한다.

읽기 전용

검토·진단·설명·계획·상태

질문→최소 조사→보고

편집, staging, 빌드, 테스트, 서버, 브라우저 조작, 외부 변경을 자동으로 시작하지 않는다.

상태 변경

수정·구현·문서·에셋

범위→start→domain→검증

보호 중인 기존 작업을 분리하고, 가장 구체적인 작업 지침을 한 단계씩 적용한다.

권한 게이트
