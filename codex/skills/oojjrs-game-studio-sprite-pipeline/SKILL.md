name: oojjrs-game-studio-sprite-pipeline
description: Game Studio의 2D 애니메이션을 동작 구간·부위별 작화와 본·메시 리깅을 자율적으로 혼합해 제작·수정한다. 단순 동작은 완전한 파츠 리그로, 복잡한 동작은 새 핵심 포즈와 구간별 리그로 만들고 필요하면 전 프레임을 재작화한다. 픽셀 단위 일관성과 실제 재생 품질을 확인한다.
---

- 사용 가능한 Game Studio의 `sprite-pipeline`과 연결 문서를 읽고 제작 판단은 `$oojjrs-2d-sprite-animation`을 따른다. 플러그인 문서가 없으면 해당 연동의 제약을 보고하고, 승인 범위에서 가능한 제작은 계속한다.
- 목표 외형·동작과 구간별 핵심 자세를 정한 뒤 작화·리깅·보정·합성을 자율적으로 조합한다. 통상적인 기법·부위·구간 선택을 사용자에게 떠넘기지 않는다.
- 본·메시 제작 전 `$oojjrs-2d-sprite-animation`의 `references/rigging-playbook.md`를 읽고 파츠 명세·좌표·바인드 포즈·본 계층·메시·가중치·FK/IK·가림·실패 수정 순서를 적용한다.
- 단순 동작도 독립적으로 움직이는 부위를 레이어·어태치먼트로 분리하고 가려진 면·관절 겹침·가림 순서를 완성한다. 통이미지 한 장의 메시 변형으로 파츠 리그를 대신하지 않는다.
- 복잡한 동작은 핵심 포즈를 새로 그리고 구간마다 적합한 파츠 리그를 구성한다. 작화 프레임과 리그 렌더를 섞고, 필요하면 전 프레임을 재작화한다.
- 구간 전환의 크기·윤곽·색·기준점·겹침을 원본 해상도에서 대조하며 필요한 만큼 재작화·정렬·리깅 수정을 반복한다. 의도한 변형과 궤적은 유지한다.
- 실제 재생의 자연스러움과 일관성으로 완료를 판단한다. Spine 결과물을 제공하거나 호환성을 주장할 때만 실제 도구 검증을 요구하며, Unity 설치는 해당 공식 CLI 규칙을 따른다.
