name: oojjrs-game-studio-sprite-pipeline
description: Game Studio 요청의 2D 애니메이션을 원본 고정, 핵심 포즈 확인, 승인 포즈를 유지한 인접 프레임 제작, 실제 재생 확인 순서로 제작·수정한다. 스트립 우선 규칙을 두지 않으며 트랜스폼은 완성 원화의 정렬·출력 준비를 보완할 때만 사용한다.
---

- Game Studio의 `sprite-pipeline`과 연결 문서를 읽고 이 제작 절차를 우선한다. 문서가 없으면 중단한다.
- 원본 고정 → 핵심 포즈 확인 → 승인 포즈를 유지하며 인접 프레임 제작 → 실제 재생 확인 순서로 진행한다.
- 스트립 생성을 우선하지 않는다. 개별·묶음 생성은 확인된 포즈의 연결을 위한 선택지이며 승인 원화를 덮어쓰지 않는다.
- 트랜스폼은 완성 원화의 공통 배율·기준점 정렬 같은 보완에만 쓴다. 변형·보간·페이드·코드 좌표 계산으로 필요한 포즈를 대신 만들지 않는다.
- `$oojjrs-2d-sprite-animation`의 제작·수정·Unity 설치 규칙을 따른다. 최신 재작업 상태를 반영하고 실제 프레임으로 시트·GIF를 조립해 확인한다.
