---

- Game Studio의 `sprite-pipeline`과 연결 문서를 읽고 이 제작 절차를 우선한다. 문서가 없으면 중단한다.
- 원본 고정 → 가려진 면까지 파츠 완성 → 본·메시 리깅 → 핵심 자세·타이밍 확인 → 필요한 부분 작화 → 실제 재생 확인 순서로 진행한다.
- 독립적으로 움직이거나 가리는 단위로 분리하고 관절의 겹침·가림 순서를 설계한다. 단단한 부위는 형태를 유지하고 휘는 부위는 메시·가중치로 제어한다.
- 새로 드러나는 면·표정·형태 변화는 추가로 그린다. 직접 작화 요청을 존중하고 승인 원화를 보존하며, 인접 작화에는 양쪽 기준 포즈를 참조한다.
- 생소한 리그·동작은 짧은 대표 동작부터 확인한다. 실제 원화·리그 렌더로 시트·미리보기를 만들고, 자체 렌더 결과와 실제 Spine 호환 검증을 구분한다.
- `$oojjrs-2d-sprite-animation`의 제작·출력·Unity 설치 규칙을 따른다. 기본 원화와 움직임의 일관성을 각각 확인하고 최신 재작업 상태를 반영한다.
