---
name: oojjrs-game-studio-sprite-pipeline
description: Game Studio 요청의 2D 애니메이션을 실제 포즈별 원화와 일관된 시퀀스로 제작·수정한다. 승인 원본을 참조해 개별 프레임, 한 동작의 스트립, 연결된 단계별 원화를 그리고 실제 프레임으로 시트와 GIF를 조립한다.
---

- Game Studio의 `sprite-pipeline`과 연결 문서를 읽고 실제 포즈 재작화 규칙을 우선한다. 문서가 없으면 중단한다.
- 승인 원본과 인접 포즈를 고정 참조해 모든 동작 포즈와 중간 프레임을 그린다. 한 호출에 개별 프레임이나 일관된 동작 스트립·단계를 제작할 수 있다.
- 트랜스폼·리깅·보간·페이드·코드 좌표 변형으로 동작을 만들지 않는다. PNG로 구워도 새로 그린 포즈로 취급하지 않는다.
- 합격한 컨셉·리듬·움직임 폭을 유지하며 문제 구간을 재작화한다. 실제 프레임을 공통 배율·기준점으로 정렬해 시트·GIF를 조립한다.
- `$oojjrs-2d-sprite-animation`의 제작·수정·Unity 설치 규칙을 따르며, 비교 요청 때만 조건을 맞춰 결과를 보존하고 비교한다.
